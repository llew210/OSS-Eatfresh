# [Eat Fresh]

한국 마트 영수증 사진을 냉장고 재료 목록과 예상 소비기한으로 바꿔 주는 오픈소스 웹 프로젝트입니다.

> **개발 중인 프로젝트입니다.** 아직 완성되지 않았고, 기능과 구조가 바뀔 수 있습니다.

## 소개

영수증에는 `농심)신라면멀티5입`처럼 줄임말과 브랜드명이 섞인 품목명이 적혀 있고, 소비기한 정보는 없습니다. 이 프로젝트는 오픈소스 OCR로 영수증의 글자를 읽은 뒤, 아래 두 가지를 직접 만들어 공개하는 것을 핵심 목표로 합니다.

1. **한국 영수증 정규화:** 품목명을 재료명으로 바꾸는 사전과 파서
2. **오픈 소비기한 데이터셋:** 재료별 보관 기간을 출처와 신뢰도와 함께 정리한 데이터

그리고 영수증 인식 정확도를 직접 측정해 결과를 공개합니다.

## 주요 기능 (계획)

- [ ] 영수증 사진에서 글자 읽기 (EasyOCR)
- [ ] 품목 줄 추출과 비식품 항목 걸러내기
- [ ] 품목명을 재료명으로 정규화
- [ ] 재료별 예상 소비기한 계산 (근거와 신뢰도 표시)
- [ ] 인식 결과를 화면에서 확인하고 수정
- [ ] 정확도 평가 리포트

현재 지원 범위: 영수증, 약 [n]개 품목 (변경 가능)

## 시작하기

### 요구 사항

- Python [3.x] (팀원 모두 같은 버전을 사용합니다)
- Git
- 처음 실행할 때 EasyOCR이 모델 파일을 내려받으므로 인터넷 연결과 저장 공간이 필요합니다.

### 설치

```bash
# 1. 저장소 내려받기
git clone https://github.com/[계정]/[저장소].git
cd [저장소]

# 2. 가상환경 만들기
python -m venv venv

# 3. 가상환경 켜기
venv\Scripts\activate          # Windows
source venv/bin/activate       # Mac, Linux

# 4. 라이브러리 설치
pip install -r requirements.txt
```

### 환경 변수 (선택 기능을 쓸 때만)

외부 AI API 같은 선택 기능을 쓸 때만 필요합니다.

```bash
cp .env.example .env           # Windows는 파일을 직접 복사해서 이름 변경
```

`.env` 파일에 값을 채웁니다. **`.env`는 Git에 올라가지 않으며, 절대 올리면 안 됩니다.**

### 실행

```bash
streamlit run app/app.py
```

실행하면 브라우저가 열립니다. 열리지 않으면 터미널에 표시된 주소(보통 `localhost:8501`)로 접속하세요.

## 폴더 구조

```

```

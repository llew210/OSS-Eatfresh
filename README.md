# Eat Fresh (잇프레쉬)

한국 마트 영수증 사진을 냉장고 재료 목록과 예상 소비기한으로 바꿔 주고, 소비기한이 임박한 재료로 만들 수 있는 레시피를 추천해 주는 오픈소스 웹 프로젝트입니다.

> **개발 중인 프로젝트입니다.** 아직 완성되지 않았고, 기능과 구조가 바뀔 수 있습니다.

## 소개

영수증에는 `농심)신라면멀티5입`처럼 줄임말과 브랜드명이 섞인 품목명이 적혀 있고, 소비기한 정보는 없습니다. 이 프로젝트는 오픈소스 OCR로 영수증의 글자를 읽은 뒤, 아래 두 가지를 직접 만들어 공개하는 것을 핵심 목표로 합니다.

1. **한국 영수증 정규화:** 품목명을 재료명으로 바꾸는 사전과 파서
2. **소비기한 참고 자료:** 식약처 품목별 소비기한 참고값 중 시연 레시피에 쓰이는 재료를 골라, 출처와 함께 정리한 자체 데이터

여기에 냉장고 재료 관리와 레시피 추천 기능을 더해, 산 재료를 버리지 않고 먹을 수 있도록 돕습니다. 영수증 인식 정확도는 직접 측정해 결과를 공개합니다.

## 지원 범위

글자 간 간격으로 품목명과 수량을 구분하는 방식이라 영수증 양식이 마트마다 다르면 같은 방법으로 읽기 어렵습니다. 그래서 범위를 의도적으로 좁혀 시작합니다.

- **영수증:** 지원 대상으로 정한 일부 마트의 영수증만 인식합니다. (지원 마트 수는 개발하며 확정)
- **레시피:** 식약처 조리식품의 레시피 DB 전체가 아니라, 시연용으로 직접 선정한 레시피 7개를 사용합니다.
- **재료:** 선정한 레시피에 쓰이는 재료를 기준으로 정규화 사전과 소비기한 참고 자료를 만듭니다.

범위 밖 영수증이나 품목은 직접 입력으로 등록할 수 있습니다.

## 주요 기능 (계획)

**영수증 처리**
- [ ] 영수증 사진에서 글자 읽기 (EasyOCR, OpenCV 전처리)
- [ ] 글자 간 간격을 계산해 품목명, 수량, 구매일 구분
- [ ] 인식이 불명확하면 품목과 수량을 직접 입력
- [ ] 구매일 인식에 실패하면 사용자에게 입력 요청
- [ ] 품목 줄 추출과 비식품 항목 걸러내기
- [ ] 품목명을 재료명과 수량으로 정규화 (예: `농심신라면멀티5입` → 라면 / 5개)
- [ ] 인식과 정규화 결과를 화면에서 확인하고 수정

**재료와 소비기한 관리**
- [ ] 재료 등록·수정·삭제 (SQLite에 저장)
- [ ] 소비기한 직접 입력·수정
- [ ] 입력하지 않은 재료는 영수증 구매일과 소비기한 참고 자료로 소비기한 계산
- [ ] 오늘 날짜와 비교해 소비기한이 임박한 재료 표시

**레시피 추천과 조리**
- [ ] 선정한 레시피(재료, 조리 방법)를 보유 재료와 비교해 충족률 계산
- [ ] 임박 재료를 쓰는 레시피 중 충족률이 높은 순으로 3개 자동 추천 (수동 검색·추천은 제공하지 않음)
- [ ] 요리를 완료하면 사용한 재료 수량을 차감하고 추천 다시 계산
- [ ] 재료가 부족한 상태에서 조리 완료를 누르면 부족한 재료와 수량을 안내하고, 확인하면 보유 수량만큼 차감해 0으로 처리
- [ ] 완성된 음식의 보관 방식(냉장/냉동) 안내

**평가**
- [ ] 지원 마트 영수증 기준 인식 정확도 평가 리포트 (성공 기준: 품목명 정확도 90% 이상)

수량 단위는 `g`과 `개`로 통일하며, 소금·간장 같은 기본 양념은 보유 재료로 간주합니다.

## 시작하기

### 요구 사항

- Python 3.11.9 (팀원 모두 같은 버전을 사용합니다)
- Git
- 처음 실행할 때 EasyOCR이 모델 파일을 내려받으므로 인터넷 연결과 저장 공간이 필요합니다.

### 설치

```bash
# 1. 저장소 내려받기
git clone https://github.com/llew210/OSS-Eatfresh.git
cd OSS-Eatfresh

# 2. 가상환경 만들기
python -m venv venv

# 3. 가상환경 켜기
venv\Scripts\activate          # Windows
source venv/bin/activate       # Mac, Linux

# 4. 라이브러리 설치
pip install -r requirements.txt
```

### 환경 변수

레시피 API 키 등을 `.env` 파일에 넣어 사용합니다. (python-dotenv가 읽어 들입니다.)

```bash
cp .env.example .env            # Windows는 파일을 직접 복사해서 이름 변경
```

`.env` 파일에 값을 채웁니다. **`.env`는 Git에 올라가지 않으며, 절대 올리면 안 됩니다.**

### 실행

> 서버 실행 명령은 진입 파일이 확정되면 이 부분에 작성합니다.

Flask 로컬 서버를 실행한 뒤, 브라우저에서 터미널에 표시된 주소(기본값은 `http://127.0.0.1:5000`)로 접속합니다.

## 개인정보 주의

영수증에는 카드번호 일부, 매장 정보, 구매 이력이 포함될 수 있습니다.

- **영수증 원본 이미지는 저장소에 올리지 않습니다.** (`data/raw_receipts/`는 Git이 무시합니다.)
- 정확도 평가용 영수증 이미지는 개인 식별 정보를 가린 뒤 저장소 밖의 팀 공유 저장소에서 관리합니다.
- 저장소에는 개인 식별 정보를 지운 **품목 텍스트와 정답 라벨**만 올립니다.
